## STEP 0.7 · 작업 폴더 열기 ①필수

> 🎯 당근 지을 땅부터. 모든 작업은 **이 폴더 안**에서.

1. 바탕화면에 폴더 생성 — **영문 소문자·하이픈만** (한글·공백 X). 예: `day1-practice`
2. Desktop → **`Code` 탭** → Environment **Local** → **`Select folder`**로 그 폴더 선택
   - (Windows) 첫 진입 시 **Git for Windows 설치** 안내가 뜨면 설치 후 앱 재시작

**⌨️ `[1-0-1]` 첫 프롬프트**
```
안녕! 이 폴더에서 새 프로젝트를 시작할 거야. 지금 폴더 안에 뭐가 있는지 확인해줄래?
```
> ✅ **확인:** AI가 "폴더가 비어 있다"고 답하면 성공. (챗봇과 달리 Claude가 내 폴더를 직접 읽음)

## STEP 2 · Firebase 설치 걸어두기 ①필수

> 🎯 설치는 좀 걸리니 **먼저 걸어두고**, 도는 동안 context7·git을 배운다.
> 🖱️ 먼저 **auto 모드** 켜기: **Mode 버튼 → Auto** (또는 Settings → Claude Code → Auto). 승인 팝업 최소화.

**⌨️ `[1-2-1]` 설치 걸어두기 · auto**
```
firebase cli 설치해줘 (firebase.google.com/docs/cli 참고). 권한 필요하면 알려줘
```
> ✅ **확인:** 설치 로그가 **주르륵 흐르기 시작하면 정상** → 그대로 두고 STEP 3으로. (끝나길 기다리지 말 것)
> 🔒 auto는 지금이라서 — 실습 폴더 격리 + git 되돌리기 가능. 집에서 **진짜 데이터 든 폴더**에선 auto 끄고 승인 켜기.

## STEP 3 · context7 — 최신 근거 쥐여주기 ①필수

> 🎯 "대충 시키면 옛날 방식, **근거(문서)를 쥐여주면 정확**"을 직접 비교 체험.

**⌨️ `[1-3-1]` 근거 없이**
```
firebase cli 최신 설치법 알려줘
```
**⌨️ `[1-3-2]` context7으로**
```
context7으로 firebase cli 최신 설치법 알려줘
```
> ✅ **확인:** `[1-3-2]` 답이 `[1-3-1]`보다 **최신 버전 번호나 더 정확한 명령**을 담고 있으면 성공. (문장이 달라도 OK, "더 최신인지"만)
> 두 답이 똑같으면 → context7 호출이 안 걸린 것. 프롬프트에 `context7으로` 명시했는지 확인.

> 💬 **MCP는 외울 필요 없어요.** 앞으로 어디서 'MCP'를 보면 — AI에 외부 서비스를 꽂는 **'전원 플러그'** 이름일 뿐. context7도 그걸 CLI로 더 간편하게 꽂은 거예요.

## STEP 4 · git — 되돌리기 안전망 ①②필수 / ③여유되면

> 🎯 커밋(세이브포인트) → 롤백(되돌리기) → 태그(이름표)를 직접.

### 4-1. git 설치 ①필수
**⌨️ `[1-4-1]` git 설치**
```
git 설치해줘. 권한 필요하면 알려줘
```
> ✅ **확인:** `git --version 확인해줘` 했을 때 **버전 숫자가 나오면** 성공. (권한 팝업은 다같이 클릭)

### 4-2. 관리 시작 + 두 페이지 만들고 커밋 ①필수
**⌨️ `[1-4-2]` 관리 시작**
```
git으로 관리 시작해줘
```
**⌨️ `[1-4-3]` 첫 페이지**
```
인사말 페이지 index.html 만들어줘
```
**⌨️ `[1-4-4]` 커밋 1**
```
커밋해줘
```
**⌨️ `[1-4-5]` 페이지 하나 더 → 커밋 2**
```
소개 페이지 about.html 만들어줘
커밋해줘
```
> ✅ **확인:** `커밋 목록 보여줘`(또는 `git log 보여줘`) 하면 **커밋이 2개** 보이면 성공. 이게 되돌아올 세이브포인트.

### 4-3. 롤백 비교 — git 없이 vs git ②필수
**⌨️ `[1-4-6]` 두 파일 조금씩 수정**
```
두 페이지 내용 조금씩 바꿔줘
```
**⌨️ `[1-4-7]` git 없이 되돌리기**
```
git 쓰지 말고 방금 수정 되돌려줘
```
**⌨️ `[1-4-8]` (다시 수정해둔 뒤) git으로 되돌리기**
```
git으로 직전 커밋으로 되돌려줘
```
> ✅ **확인:** `[1-4-8]` 후 두 페이지가 **커밋했던 상태 그대로** 돌아왔으면 성공.
> 👉 `[1-4-7]` git 없이(AI 기억으로) 한 건 "한 파일은 됐는데 다른 건 어정쩡"할 수 있어요 — **그 차이를 눈으로 대조**하는 게 이 실습의 핵심.
> 💬 AI 기억으로 되돌리기 = **사람 기억(헷갈림)**, 커밋 = **찰칵 찍은 사진(정확)**. 그래서 헷갈릴 일 있는 작업일수록 사진을 자주 찍는(=자주 커밋) 거예요.

### 4-4. 태그 = 이름표 북마크 ③여유되면
**⌨️ `[1-4-9]` 태그 붙이기**
```
지금 커밋에 day1-done 태그 붙여줘
```
**⌨️ `[1-4-10]` 수정 한 번 → 태그로 롤백**
```
index.html 배경색 바꿔줘
day1-done 태그로 되돌려줘
```
> ✅ **확인:** 방금 바꾼 배경색이 **사라지고** 태그 붙였던 상태로 돌아왔으면 성공.
> 💬 커밋 해시(`f3a2b1`)보다 이름(`day1-done`)이 직관적이라 "세이브포인트로 점프"가 됩니다. 전부 로컬 git만으로 작동(GitHub 불필요).

## STEP 5 · Firebase 마무리 — 로그인·프로젝트 ①필수

> 🎯 걸어둔 설치가 끝났으니, 로그인하고 테스트 프로젝트까지.

**⌨️ `[1-5-1]` 로그인 · 사람 클릭 개입**
```
firebase login 해줘
```
> ✅ **확인:** 브라우저에 **"로그인 완료"** 화면이 뜨면 성공.
> ⚠️ AI가 실행하면 브라우저 인증창이 자동으로 열림 → **본인 구글 계정으로 로그인**.

**⌨️ `[1-5-2]` 테스트 프로젝트 생성**
```
firebase 테스트 프로젝트 만들어줘
```
> ✅ **확인:** Firebase 콘솔(`console.firebase.google.com`) 새로고침 → 방금 만든 **프로젝트가 목록에 보이면** 성공.

**⌨️ `[1-5-3]` 프로젝트 삭제**
```
방금 프로젝트 삭제해줘
```
> ✅ **확인:** 콘솔에서 그 프로젝트가 **사라졌으면** 성공.
> 👉 설치·로그인만 해두면, 프로젝트 만들고 지우는 건 **말 한마디로** 됩니다. 2회차엔 이 위에 진짜 당근을 올려요.

## 🎁 보너스 · 시간 남으면 (skill · hook)

> 본강의에서 안 다룬 Claude Code 고유 기능. 빠듯하면 건너뛰어도 OK.

**skill = 단골 주문서.** 자주 시키는 일을 한 번 저장 → `/이름` 한 줄로 재호출. 실체는 파일 하나(`.claude/skills/이름/SKILL.md`). **말로 만들면 됨.**

**⌨️ `[1-B-1]` skill 만들기 (2회차 예고 삼아)**
```
2회차에 미니 당근에서 '더미 상품 데이터 만들기'를 자주 할 거야.
'우리 규격의 더미 상품(상품명·가격·동네, 진짜 개인정보 금지)을 만드는' 작업을
재사용 가능한 skill로 만들어줘. 이름은 dummy-goods.
```
> ✅ **확인:** `/dummy-goods`가 슬래시 목록에 뜨면 성공. (SKILL.md 열어 내용 읽어보기)

**hook = 자동 비서** (개념만). skill이 '내가 불러서'라면, hook은 '특정 순간 알아서'(예: 커밋 전 자동 검사). `settings.json`에 '언제→뭘'을 적어둠. 필요할 때 AI에게 `hook으로 만들어줘` 하면 됨.

> 💬 skill은 **내 단골 주문서**, hook은 **자동 비서**. 오늘은 맛만.

## ✋ 진행 약속 (매 회차 공통)

1. **화면이 달라도 정상** — AI는 매번 조금씩 다르게 답해요. 색·문구가 달라도 틀린 게 아닙니다.
2. **정답은 화면이 아니라 ✅ 확인 포인트** — 그것만 맞으면 통과.
