# 🌱 1회차 복습 카드 — 집에서 처음부터 그대로 따라하기

> 오늘 놓친 부분이 있어도 괜찮아요. 이 카드만 있으면 **혼자 처음부터 끝까지** 다시 할 수 있습니다.
> **회색 상자 안의 문장을 그대로 복사**해서, Claude에게 붙여넣고 Enter만 누르면 돼요.
> 명령어를 외울 필요 없어요 — **한국어로 "~해줘"라고 말하면 AI가 알아서** 합니다.

> 🎯 **오늘의 목적지:** 4주 뒤 만들 **미니 당근**의 "지을 땅 고르기" — 되돌릴 수 있는 폴더(git) + Firebase 세팅.

---

## 📌 시작하기 전에 — 딱 3가지만 알아두세요

1. **우리는 명령어를 직접 안 칩니다.** AI에게 한국어로 시키고, AI가 대신 명령어를 실행해요.
2. **AI가 "실행할까요?"라고 물으면** → 허용하면 됩니다 (또는 **auto 모드**면 안 물어봄).
3. **뭔가 이상하면 당황하지 마세요.** git으로 언제든 되돌릴 수 있어요(뒤에서 배웁니다).

> 💡 **어디서 실행하나요?** **Claude Desktop 앱의 `Code` 탭**입니다(챗봇 대화창 아님). Code 탭은 **내 폴더를 직접 읽고 고쳐요.** 폴더 열기·모델 선택·auto·권한이 전부 화면 버튼으로 됩니다.

> 💡 **auto 모드**: 매번 "실행할까요?" 안 묻고 안전한 건 알아서 진행하는 모드. **제목줄의 `Mode` 버튼 → `Auto`**로 켜요. (집에서 **진짜 데이터 든 폴더**에선 끄고 승인 켜두는 게 안전 — 오늘은 격리된 연습 폴더라 켜고 시작해도 OK.)

# STEP 0. 작업 폴더 열기 (맨 처음 한 번)

**왜?** 오늘 만들 파일들을 한 곳에 모아두고, git·Firebase를 **이 폴더에** 걸려고요.

**① 바탕화면에 폴더를 하나 만드세요. 이름은 영문 소문자·하이픈만:**
```
day1-practice
```
> ⚠️ 폴더명에 **한글·공백이 섞이면 경로 문제**가 생겨요. 꼭 영문으로.

**② Desktop 앱 → `Code` 탭 → Environment는 `Local` → `Select folder` 버튼으로 방금 그 폴더를 선택.**

**③ 첫 프롬프트로 폴더를 확인하세요:**
```
안녕! 이 폴더에서 새 프로젝트를 시작할 거야. 지금 폴더 안에 뭐가 있는지 확인해줄래?
```
> ✅ **확인:** AI가 "폴더가 비어 있다"고 답하면 성공. **방금 연 이 폴더가 곧 git·Firebase의 무대**예요.

> 💡 (Windows만) 첫 Code 탭 진입 때 **Git for Windows 설치 안내**가 뜰 수 있어요 → 뜨면 설치하고 앱 재시작. 그럼 뒤의 git 설치는 건너뛰어도 됩니다.

---

# STEP 1. Firebase 설치 걸어두기 (2회차부터 쓸 백엔드 도구)

**왜 먼저?** 설치가 좀 걸려요. **걸어두고**, 도는 동안 다른 도구(context7·git)를 배웁니다.

**① auto 모드부터 켜기:** 제목줄 **`Mode` 버튼 → `Auto`**. (승인 팝업이 줄어 실습이 매끄러워요.)

**② 설치 걸어두기:**
```
firebase cli 설치해줘 (firebase.google.com/docs/cli 참고). 권한 필요하면 알려줘
```
> ✅ **확인:** 설치 로그가 **주르륵 흐르기 시작하면 정상.** 끝나길 기다리지 말고 그대로 두고 다음 단계로.

**만약 권한 팝업이 뜨면?** (설치 프로그램 창·비밀번호 요구 등) → **당황 말고 직접 클릭/입력해서 허용**하세요. 이건 정상이에요.

> 💡 **Firebase가 뭐예요?** 백엔드(데이터 저장·로그인·실시간)를 **직접 안 만들고 빌려 쓰는** 서비스. 2회차부터 이 위에 진짜 당근을 올려요.

---

# STEP 2. context7 효과 체험하기 (근거 없이 vs context7으로)

**왜?** context7이 왜 좋은지 직접 눈으로 비교해보려고요. **context7은 최신 문서를 AI 손에 쥐여주는 도구**예요 — 따로 설치할 필요 없이 문장 앞에 `context7으로`만 붙이면 돼요.

**① 먼저 근거 없이 물어보세요:**
```
firebase cli 최신 설치법 알려줘
```
**② 이번엔 context7으로 물어보세요:**
```
context7으로 firebase cli 최신 설치법 알려줘
```
> ✅ **확인:** ②번 답이 ①번보다 **더 최신 버전 번호나 정확한 명령**을 담고 있으면 성공. (문장이 달라도 OK — "더 최신인지"만 봐요.) 두 답이 똑같으면 `context7으로`가 안 걸린 것 → 문장 앞에 붙였는지 확인.

> 💡 **꼭 기억:** 최신 정보가 필요할 땐 매번 **"context7으로"**를 문장 앞에 붙이세요. 진가는 설치법보다 **라이브러리 최신 문법·새 기능**에서 나와요.

# STEP 3. git으로 저장하고 되돌리기 (제일 중요!)

> git은 **게임의 세이브포인트**예요. 저장(커밋)해두면, 망가져도 그 지점으로 돌아갈 수 있어요.

### 3-1. git 설치하고 관리 시작하기

**① 설치:**
```
git 설치해줘. 권한 필요하면 알려줘
```
> ✅ **확인:** `git --version 확인해줘` 했을 때 **버전 숫자가 나오면** 성공. (Windows에서 STEP 0 때 이미 깔았다면 버전만 확인하고 넘어가요.)

**② 관리 시작:**
```
git으로 관리 시작해줘
```
> ✅ **확인:** "git 저장소를 초기화했습니다" 같은 메시지. 이제부터 저장이 가능해요.

### 3-2. 페이지 2개 만들고 → 각각 저장(커밋)하기

```
# ① 첫 페이지
인사말 페이지 index.html 만들어줘

# ② 저장(커밋) — 첫 세이브포인트
커밋해줘

# ③ 페이지 하나 더
소개 페이지 about.html 만들어줘

# ④ 또 저장
커밋해줘
```
> ✅ **확인:** `커밋 목록 보여줘` 하면 **커밋이 2개** 보이면 성공. 이게 되돌아올 세이브포인트예요.

> 💡 **작업할 때마다 커밋**하세요. 세이브포인트가 촘촘할수록 안전해요.

---

# STEP 4. 되돌리기 두 가지 방법 배우기

> 되돌리는 방법은 두 가지예요. **git 없이**(AI 기억으로) vs **git으로**(찍어둔 커밋 지점으로).
> 🔑 **핵심:** 되돌리려면 **먼저 커밋(사진)을 찍어둬야** 해요. 그래서 아래 ③에서 커밋을 찍고 ⑤에서 그 지점으로 돌아갑니다.

```
# ① 두 페이지 조금씩 수정
두 페이지 내용 조금씩 바꿔줘

# ② git 없이 (AI 기억으로) 되돌리기
git 쓰지 말고 방금 수정 되돌려줘

# ③ 다시 수정한 뒤, 이 상태를 커밋 (되돌아올 지점을 여기서 만든다)
두 페이지 또 조금 바꾸고, 이 상태를 커밋해줘

# ④ 한 번 더 수정
두 페이지 또 조금 바꿔줘

# ⑤ 방금 커밋으로 되돌리기
방금 커밋으로 되돌려줘
```
> ✅ **확인:** ⑤ 후 두 페이지가 **③에서 커밋한 상태 그대로** 돌아왔으면 성공. ②(git 없이)는 "한 파일은 됐는데 다른 건 어정쩡"할 수 있어요 — **그 차이를 눈으로 대조**하는 게 이 실습의 핵심이에요.

> 🔑 **한 줄 봉인:** git 없이 되돌리기 = "어제 뭘 어디까지 고쳤더라…" 하는 **사람 기억(헷갈림)**. 커밋 = 그 순간을 **찰칵 찍어둔 사진(정확)**. **되돌리려면 먼저 사진을 찍어둬야** 해요.

---

# STEP 5. 태그(이름표)로 되돌리기

> 태그는 커밋에 **이름을 붙이는 것**이에요. `day1-done` 같은 이름을 부르면 그 지점으로 점프!

```
# ① 지금 커밋에 이름표 붙이기
지금 커밋에 day1-done 태그 붙여줘

# ② 한 번 더 수정해보기
index.html 배경색 바꿔줘

# ③ 이름표로 한 번에 되돌아가기
day1-done 태그로 되돌려줘
```
> ✅ **확인:** 방금 바꾼 배경색이 **사라지고** 태그 붙였던 상태로 돌아왔으면 성공. 커밋 해시(`f3a2b1`)보다 **이름('day1-done')**이 직관적이라, 이게 "세이브포인트로 점프"가 됩니다.

> 💡 전부 **로컬 git만으로** 작동해요 (GitHub 불필요). 백업이 필요하면 폴더째 zip.

# STEP 6. Firebase 로그인 & 프로젝트 (2회차 준비운동)

> 아까 걸어둔 Firebase 설치, 그새 끝났죠? 이제 로그인하고 마무리합니다.
> 여기가 **사람이 직접 하는 유일한 단계**예요. 겁먹지 마세요, 클릭 한 번이에요.

### 6-1. 로그인하기

```
firebase login 해줘
```
**그러면?** 브라우저(인터넷 창)가 자동으로 열려요.
**직접 할 일:** **본인 구글 계정을 클릭** → 로그인 → 인증이 끝나면 Code 탭으로 자동 복귀.
> ✅ **확인:** 브라우저에 **"로그인 완료"** 화면이 뜨면 성공.
> 💡 왜 이것만 직접? 구글 계정 보안 때문이에요. 그 외엔 전부 AI가 합니다.

### 6-2. 테스트 프로젝트 만들어보고 지우기

```
# ① 만들기
firebase 테스트 프로젝트 만들어줘
```
> ✅ **확인:** Firebase 콘솔(`console.firebase.google.com`) 새로고침 → 방금 만든 **프로젝트가 목록에 보이면** 성공.

```
# ② 연습이니까 지우기
방금 프로젝트 삭제해줘
```
> ✅ **확인:** 콘솔에서 그 프로젝트가 **사라졌으면** 성공.

> 💡 2회차에는 이 위에 **진짜 미니 당근**을 올릴 거예요. 오늘은 "된다"는 것만 확인!

# 📖 용어 미니사전

- **CLI** : 명령어로 컴퓨터를 다루는 방식. 우리는 AI에게 말로 시키고, AI가 명령어를 대신 침.
- **Code 탭** : Claude Desktop 앱에서 **내 폴더를 직접 읽고 고치는** 작업 공간(챗봇 대화창과 다름).
- **커밋(commit)** : 지금 상태를 저장하는 것 = 세이브포인트.
- **롤백(rollback)** : 이전 커밋 지점으로 되돌아가는 것.
- **태그(tag)** : 커밋에 붙이는 이름표(예: day1-done). 나중에 이름으로 되돌아올 수 있음.
- **auto 모드** : AI가 안전한 작업은 안 묻고 알아서 진행하는 모드 (`Mode` 버튼 → `Auto`).
- **백엔드** : 데이터 저장·로그인·서버 같은 "화면 뒤" 기능. Firebase가 대신 해줌.
- **Firebase** : 백엔드를 빌려주는 서비스 (2회차부터 본격 사용).
- **context7** : AI에게 라이브러리 최신 설명서를 찾아 쥐여주는 도구 (문장 앞에 `context7으로`).
