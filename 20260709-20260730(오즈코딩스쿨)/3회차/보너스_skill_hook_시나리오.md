# 🎁 보너스 시나리오 — skill · hook (1회차 · 시간 남으면)

> 1회차 6장 마무리 뒤 **진도 여유 시에만**. ~15분. 핵심 아님 → 빠듯하면 통째 생략.
> 목적: 본강의가 안 다룬 **Claude Code 고유 기능** 맛보기. 대본이라 강사가 읽으며 진행.

## 사양 메모 (강사용 · 2026-07 공식문서 확인)

- **skill 실체**: `.claude/skills/<이름>/SKILL.md` (YAML frontmatter: `name`·`description` + 마크다운 지시문). 호출: `/이름` 또는 자연어 자동(description 매칭). Desktop Code 탭에서도 됨(파일 편집으로 생성/`/`로 호출).
- **skill 만드는 법(비전공자용)**: 파일 직접 X → **"이 작업을 skill로 만들어줘"** 하면 Claude가 SKILL.md 생성. **skill-creator**(Anthropic 공식 스킬)가 이 과정을 돕는다 — 실제 설명: *"Create new skills, modify and improve existing skills, and measure skill performance."* 초안 작성→테스트→개선 루프. 비전공자는 **초안 생성까지만**, evals/benchmark는 과함.
- **hook 실체**: `settings.json`의 이벤트 핸들러(`PreToolUse`·`PostToolUse`·`Stop`·`UserPromptSubmit` 등 → 셸 명령/프롬프트 실행). 백그라운드 자동. Desktop에서도 작동.
- ⚠️ **강의 전날 실제 Desktop에서 1회 확인** (앱 자동 업데이트).

## B-1. skill — "단골 주문서" (개념 + 미니실습)

### ① 비유로 열기 (1분)
> 🗣 "이번 특강 내내 뭐라고 했죠? **'프롬프트가 여러분 자산'**. 근데 자산인데 매번 똑같은 긴 프롬프트를 처음부터 다시 치면 아깝잖아요."
> 🗣 "**카페 단골** 되면 '늘 마시던 거요' 한마디면 끝나죠. **skill이 딱 그거**예요. 자주 시키는 일을 한 번 저장 → 다음부턴 `/이름` 한 줄로 그 긴 프롬프트가 통째로 불려나와요."
> 🗣 (안심) "거창한 거 아니에요 — `.claude/skills/이름/SKILL.md` **파일 하나**입니다."

### ② 어떻게 만드나 (1분)
> 🗣 "직접 파일 짜는 거 아니에요. **'이 작업을 skill로 만들어줘'** 하면 Claude가 SKILL.md를 알아서 씁니다. 공식 도구 **skill-creator**가 초안 작성·다듬기를 돕고요."

### ③ 미니실습 — 2회차 예고 삼아 (3분)
> 🗣 "1회차엔 아직 당근이 없으니, **2회차에 만들 걸 미리 skill로** 준비해둘게요."

**⌨️ (직접 타이핑)**
```
2회차에 미니 당근에서 '더미 상품 데이터 만들기'를 자주 할 거야.
'우리 규격의 더미 상품(상품명·가격·동네, 진짜 개인정보 금지)을 만드는' 작업을
재사용 가능한 skill로 만들어줘. 이름은 dummy-goods.
```

> ✅ **확인:** `.claude/skills/dummy-goods/SKILL.md` 생성 + `/`를 치면 목록에 `/dummy-goods`가 뜸.
> 🗣 "**열어서 읽어보세요.** 여러분이 말한 규칙(상품명·가격·동네, 개인정보 금지)이 매뉴얼로 적혀 있죠? 그게 skill이에요."

> 🗣 착지: "2회차엔 이 `/dummy-goods` **한 줄**로 더미를 채웁니다. 매번 긴 설명 대신 한 줄."

### ④ (여유 더 있으면) skill-creator 맛보기 — 선택
> 🗣 "방금 만든 skill이 **잘 도는지 테스트**도 할 수 있어요. `skill-creator`로 몇 개 예시를 돌려보고 결과를 비교하는 건데 — 비전공자에겐 좀 깊으니 **'이런 것도 있다'** 정도만 알아두세요. 필요할 때 'skill-creator로 내 스킬 평가해줘' 하면 됩니다."
> ⚠️ 강사 note: evals/benchmark/JSON은 비전공자에 과함. 여기서 멈추는 게 안전.

## B-2. hook — "자동 비서" (개념 맛보기만, 실습 X)

### ① 개념 (1분)
> 🗣 "skill이 **'내가 불러서'** 쓰는 거라면, hook은 **'특정 순간 알아서'** 도는 거예요."
> 🗣 비유: "git에도 hook 있죠 — 커밋 전 자동 검사. Claude Code hook도 똑같아요: **'응답 끝나면 / 파일 바뀌면 / 커밋 전에' 자동 실행**."
> 🗣 실체: "`settings.json`에 '언제 → 뭘 할지'를 적어두는 것."

### ② 대표 예시 하나 (1분, 말로만)
> 🗣 "예를 들어 **'커밋하기 전에 자동 코드 검사'** — 실수로 이상한 걸 커밋하는 걸 막아줘요."
> ⚠️ 강사 note: hook은 백그라운드라 눈에 덜 보임 → 비전공자엔 skill보다 안 와닿음. **개념만** 던지고 "필요해지면 AI에게 'hook으로 만들어줘' 하면 됨"으로 끝.

### ③ 착지
> 🗣 "**skill은 내 단골 주문서, hook은 자동 비서.** 오늘은 맛만 봤고, 필요할 때 AI에게 시키면 돼요."

## 생략/축약 가이드 (진도별)

| 남은 시간 | 진행 |
|---|---|
| **~2분** | B-1 ①②만 (비유+"말로 만든다") 구두, 실습 생략 |
| **~7분** | B-1 ①②③ (skill 미니실습까지) |
| **~12분** | B-1 전체 + B-2 개념 |
| **~15분** | 위 + B-1 ④ skill-creator 맛보기 |
| **빠듯** | 통째 생략 — "이런 게 있으니 핸드아웃 보세요"로 대체 |

> 핵심은 skill 미니실습(B-1③). hook은 순수 개념. skill-creator는 있으면 좋은 덤.
