## 2. 배포 다음 — URL이 생기고 나면

배포는 끝이 아니라 시작입니다. 순서대로 네 가지.

### 2-1. 검색에 등록하기 — 안 하면 SEO 절반만 한 겁니다

오늘 `robots.txt`와 `sitemap.xml`을 만들었죠. 그런데 **구글에 "여기 있어요"라고 알려주는 건 별개**입니다. 등록해야 사이트맵을 읽어갑니다.

**Google Search Console** — `https://search.google.com/search-console`

1. 속성 추가 → **URL 접두어**에 내 주소 입력 (`https://프로젝트명.web.app`)
2. 소유 확인 (HTML 파일 업로드 또는 메타 태그 — **AI에게 시키면 됩니다**)
3. 왼쪽 메뉴 **Sitemaps** → `sitemap.xml` 제출

```
Search Console 소유 확인용 파일/메타태그를 랜딩페이지에 넣어줘.
확인 코드는 이거야: (콘솔에서 복사한 값)
```

> ⏱ 등록해도 검색 결과에 뜨는 데는 **며칠~몇 주** 걸립니다. 등록하고 잊고 지내세요.

> 📚 **AI 검색까지 더 파고 싶으면** — `https://github.com/aldegad/awesome-geo`
> 오늘 다룬 **AEO/GEO 체크리스트**의 근거 저장소입니다. *"공식 문서 기반(official-doc-backed)"* 이라고 스스로 밝혀둔 점이 신뢰 요소예요. 단, **목록은 출발점이지 보증서가 아닙니다** — 4점검하고 쓰세요.

### 2-2. 몇 명 왔는지 보기

**두 단계로 나눠 생각하세요.**

| 알고 싶은 것 | 보는 곳 |
|---|---|
| 트래픽·용량이 무료 한도를 넘었나 | Firebase 콘솔 → **Hosting → 사용량** |
| **누가 · 어디서 · 어떤 페이지를** 봤나 | **Google Analytics** 를 붙여야 함 |

Firebase 프로젝트를 만들 때 Analytics를 함께 켰다면 이미 절반은 됐습니다. 랜딩에 붙이는 것만 남았어요.

```
이 랜딩페이지에 Google Analytics 붙여줘.
Firebase 프로젝트에 이미 있는 측정 ID(G-로 시작하는 것)를 쓰고,
어떤 값이 필요한지 먼저 알려줘
```

> 🔎 측정 ID는 Firebase 콘솔 → 프로젝트 설정 → 내 앱의 설정값(`measurementId`)에 있습니다. **`G-`로 시작**합니다.

> ⚠️ **오늘 만든 처리방침과 맞춰야 합니다.** 방문 기록을 수집하기 시작하면, 처리방침의 *"자동 수집 장치"* 항목이 실제와 달라집니다. Analytics를 붙이면 **처리방침도 같이 고치세요** — *"Analytics를 붙였어. 처리방침의 자동 수집 항목 갱신해줘"*

### 2-3. 내 도메인 붙이기

`프로젝트명.web.app` 대신 `내가게.com`으로 바꾸는 단계입니다.

**먼저 도메인을 삽니다** (오늘 말씀드린 대로 **카드 결제는 사람이** 합니다)

| 등록업체 | 주소 |
|---|---|
| 호스팅케이알 | `https://www.hosting.kr` |
| 가비아 | `https://www.gabia.com` |

> 💰 국내 업체가 한국어 지원·국내 카드 결제가 편합니다. 다만 **결제 전에 원하는 도메인으로 두 곳 다 검색해 `갱신가`까지 비교**하세요. 첫 해만 싸고 갱신할 때 오르는 경우가 있습니다. (강사도 가격은 매번 확인합니다)

**그다음 Firebase에 연결합니다** — 콘솔 → Hosting → **커스텀 도메인 추가**

1. 도메인 입력 → Firebase가 **TXT 레코드**를 보여줌 → 등록업체 DNS 설정에 추가 (**소유 확인용**)
2. 확인되면 **A 레코드**를 알려줌 → 그대로 추가
3. **SSL 인증서(https)는 Firebase가 자동 발급**합니다

> ⏱ DNS는 반영에 **최대 24시간** 걸립니다. 안 되면 기다려보세요 — 잘못한 게 아닐 수 있습니다.
> ⚠️ TXT 레코드는 **지우면 안 됩니다.** 인증서를 자동 갱신하는 데 계속 쓰입니다.

DNS 설정 화면이 낯설면 그대로 물어보세요.

```
가비아에서 DNS 레코드 추가하는 화면인데, Firebase가 준 이 값들을
어디에 어떻게 넣어야 하는지 알려줘: (콘솔에서 복사한 값)
```

### 2-4. 오류가 났는지 **내가 먼저** 아는 방법

가장 무서운 건 **사용자는 겪었는데 나는 모르는 오류**입니다. 배포 전에는 내 화면에서 다 보였지만, 이제는 안 보입니다.

가장 가벼운 시작은 **에러 수집을 붙이는 것**입니다.

```
사용자 화면에서 에러가 나면 내가 알 수 있게 해줘.
무료로 시작할 수 있는 방법 몇 개를 먼저 비교해서 알려주고,
장단점까지 말해줘. 고르는 건 내가 할게
```

> 💡 **왜 "비교해서 알려줘"인가** — 4주 내내 한 방식입니다. **선택지를 받고, 고르는 건 나.** 도구 이름을 제가 정해드리면 그게 최신이 아닐 수 있고, 여러분 서비스에 안 맞을 수도 있어요.

**당장 할 수 있는 최소한**도 있습니다.

- 매일 한 번 **내 폰으로** 접속해보기 (오늘 배운 👀 눈 검수, 배포 후 버전)
- 지인 두세 명에게 링크 보내고 **"안 되는 데 있으면 알려주세요"** 부탁하기
- Firebase 콘솔 → Firestore **사용량**이 갑자기 튀면 뭔가 잘못 돌고 있다는 신호
