## 오즈코딩스쿨 AI리더 7기 열정반 특강

> 2시간 × 4회 · 대상: 비전공 창업가 · 소재: **미니당근**(동네 중고거래 서비스)
> 매 회차 수강생이 직접 프롬프트를 타이핑해 결과물을 손에 남기는 방식으로 진행했습니다.

| 회차 | 주제 | 남는 것 |
|---|---|---|
| **1회차** — 바이브 코딩 매끄럽게 | CLI · Firebase 설치 · context7 · git | 커밋·태그가 있는 폴더, 그날 친 프롬프트 |
| **2회차** — 당근을 올린다 | PRD로 의도 주기 · 엣지케이스 · 한 방 발사 · `/check` 스킬 | 돌아가는 중고거래 게시판 |
| **3회차** — 당근이 살아 움직입니다 | superpowers · brainstorming · TDD · 보안 규칙 · 검수 3종 | 실시간 채팅 + 잠긴 보안 규칙 |
| **4회차** — 마지막 다듬기 | 디자인 · 랜딩페이지 · SEO/AEO · 처리방침 · 배포 | 남에게 보낼 수 있는 URL |

### 특강이 남기려 한 것

도구는 바뀝니다. 네 가지는 안 바뀝니다.

| | 쥐고 있을 것 | 쓴 것 |
|---|---|---|
| 1 | **되돌릴 지점** | 커밋 · 태그 |
| 2 | **의도** | PRD · DESIGN.md |
| 3 | **합격 기준** | TDD · lighthouse |
| 4 | **내 눈으로 확인** | 매 단계 끝 👀 |

## 파일 보는 법

각 회차 폴더에 두 가지가 있습니다.

| 파일 | 무엇 |
|---|---|
| `N회차_강의안_독립형.html` | **발표용 슬라이드.** 이미지·폰트가 전부 안에 들어 있어 **다운로드해서 브라우저로 바로** 열립니다 (인터넷 불필요) |
| `핸드아웃_*` | 수강생 배포용 (md · PDF) |

**핸드아웃 두 종류**

- `핸드아웃_기초_복습카드` — 집에서 그날 순서를 그대로 다시 밟는 카드 (프롬프트 전문 포함)
- `핸드아웃_심화_확장가이드` — 더 파고 싶을 때의 도구·다음 단계

슬라이드 조작: `←` `→` 또는 `Space`
